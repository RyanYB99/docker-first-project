# My First Docker Project

This is my first Docker container project.  
It uses an Alpine Linux base image and prints a message when the container runs.

## Files

- **Dockerfile** — defines the container
- **README.md** — documentation for the project

## How to Build

Run this command inside the project folder:

docker build -t my-first-container .

## How to Run

docker run my-first-container

## Output

Helllo, World!

## What I learned
- how to create dockerfile
- how to build a docker image
- how to run a docker container
- how to organize a devOps project
